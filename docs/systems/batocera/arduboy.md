# Arduboy
The [Arduboy](https://www.arduboy.com/) is a portable developed by Kevin Bates. It was released in 2015.

This system scrapes metadata for the "arduboy" group(s) and loads the `arduboy` set from the currently selected theme, if available.

### Quick reference
- **Emulator:** [RetroArch](#retroarch)
- **Core:** [libretro: arduous](#libretro:_arduous)
- **Folder:** `/userdata/roms/arduboy`
- **Accepted ROM formats:** `.hex`, `.zip`, `.7z`

## BIOS
No Arduboy emulator in Batocera needs a BIOS file to run.

## ROMs
Place your Arduboy ROMs in `/userdata/roms/arduboy`.
