# SAM Coupé
The SAM Coupé is a computer developed by Miles Gordon Technology. It was released in 1989.

This system scrapes metadata for the "samcoupe" group(s) and loads the `samcoupe` set from the currently selected theme, if available.

### Quick reference
- **Emulator:** [samcoupe](#samcoupe)
- **Folder:** `/userdata/roms/samcoupe`
- **Accepted ROM formats:** `.cpm`, `.dsk`, `.sad`, `.mgt`, `.sdf`, `.td0`, `.sbt`, `.zip`

## BIOS
No SAM Coupé emulator in Batocera needs a BIOS file to run.
